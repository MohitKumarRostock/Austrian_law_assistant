# KAHM comparison against stronger baselines

This report compares KAHM to evaluation-matched baselines that preserve the same deployment contract: IDF–SVD query features in, retrieval against a frozen Mixedbread corpus index out.

The added neural baselines remain law-wise models with the same prototype-distance gating used for the existing non-neural baselines, so the distributed-law serving setup is unchanged.
